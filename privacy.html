Privacy notice

Last updated: October 24, 2026

What this version does

NI Software Labs is a small project website. The included browser tools process the text and code you enter locally in your browser. This static site does not include an application database, analytics tracker, account system, or server endpoint that stores tool inputs.

Idea suggestions

The idea form prepares an email draft addressed to nivaas9293@gmail.com using your device’s default email app. It does not silently send the message. You decide whether to send it. Your email provider then handles the message under its own privacy policy.

Browser storage

The appearance preference may be stored in your browser’s local storage. Your browser may also cache site files. You can clear these through your browser settings.

External services

The stylesheet optionally loads fonts from Google Fonts. Your browser may connect to Google to retrieve those fonts. The website can still display using fallback fonts if the service is unavailable. Hosting providers may process standard technical request logs.

Security note

Do not paste passwords, private keys, sensitive personal data, or confidential code into any online tool unless you understand its behavior. Base64 is not encryption. The code playground runs entered code in a sandboxed iframe, but you should still only run code you trust.
